Política de Privacidad

```

Última actualización: 16 de septiembre de 2026

1. Responsable de la aplicación

La aplicación Calculadora para supermercado es un desarrollo propio de ElherDeveloper.

Para consultas relacionadas con privacidad, protección de datos o el funcionamiento de la aplicación, puede contactarse al siguiente correo electrónico:

hervegadev@gmail.com

2. Información que maneja la aplicación

La aplicación permite al usuario registrar y administrar información relacionada con sus compras y gastos.

Para proporcionar sus funciones, la aplicación puede almacenar localmente en el dispositivo del usuario los siguientes datos introducidos por este:

  • Descripción o nombre del producto o gasto.
  • Importe.
  • Fecha y hora del registro.
  • Un identificador interno generado por la aplicación para identificar cada registro.

Estos datos se utilizan exclusivamente para permitir al usuario registrar, consultar, ordenar y eliminar sus gastos dentro de la aplicación.

3. Almacenamiento local

La información registrada mediante la aplicación se almacena localmente en el dispositivo del usuario, mediante un sistema de almacenamiento interno de la aplicación.

La aplicación no utiliza actualmente un servidor propio ni un servicio de almacenamiento en la nube para sincronizar los gastos registrados.

Por lo tanto, los registros creados en la aplicación permanecen en el dispositivo en el que fueron generados, salvo que el propio usuario realice alguna acción externa que implique compartirlos o transferirlos.

4. Recopilación y transmisión de datos personales

La aplicación no requiere la creación de una cuenta de usuario y no solicita directamente datos personales como:

  • Nombre y apellido.
  • Documento de identidad.
  • Dirección.
  • Número de teléfono.
  • Correo electrónico del usuario.
  • Ubicación geográfica.
  • Contactos.
  • Fotografías.
  • Grabaciones de audio.
  • Información biométrica.

La aplicación tampoco transmite los registros de gastos almacenados localmente a servidores operados por ElherDeveloper.

5. Compartición de información con terceros

ElherDeveloper no vende, alquila ni comparte con terceros la información almacenada por el usuario mediante la aplicación.

La versión actual de la aplicación tampoco incorpora servicios de publicidad, análisis de comportamiento, redes sociales, servicios de autenticación o servicios externos destinados a recopilar los datos registrados por el usuario.

6. Identificadores internos

La aplicación utiliza un identificador interno para distinguir los diferentes registros de gastos.

Este identificador se utiliza exclusivamente para administrar los registros dentro de la aplicación y no se utiliza para identificar personalmente al usuario ni para realizar seguimiento de su actividad.

7. Seguridad

La información registrada se almacena localmente en el dispositivo del usuario. ElherDeveloper no recibe una copia de dichos registros mediante la aplicación.

El usuario debe tener presente que ninguna forma de almacenamiento electrónico puede garantizar una seguridad absoluta. La protección del dispositivo, incluido el uso de mecanismos de bloqueo y seguridad proporcionados por el sistema operativo, es responsabilidad del usuario.

8. Conservación y eliminación de la información

Los registros permanecen almacenados en el dispositivo mientras el usuario no los elimine.

La aplicación proporciona funciones para eliminar registros individuales y para eliminar los registros almacenados.

Asimismo, la eliminación de los datos de la aplicación mediante las funciones correspondientes del sistema operativo o la desinstalación de la aplicación puede eliminar la información almacenada localmente, de acuerdo con el funcionamiento del dispositivo y del sistema operativo.

Como la aplicación no mantiene actualmente una copia de los registros en servidores de ElherDeveloper, no existe una base de datos remota de estos registros que deba ser eliminada mediante una solicitud al desarrollador.

9. Menores de edad

La aplicación no está diseñada para recopilar deliberadamente información personal de menores de edad.

Dado que la aplicación no requiere la creación de cuentas ni solicita datos personales para su funcionamiento, no se establece un procedimiento especial de registro de usuarios menores.

10. Cambios en esta Política de Privacidad

Esta Política de Privacidad podrá actualizarse cuando se incorporen nuevas funcionalidades o se modifique la forma en que la aplicación trata la información.

Cuando se produzcan cambios relevantes, se actualizará la fecha indicada al comienzo de esta política y se publicará la versión actualizada en la misma dirección web.
```
